# Big Data Input — Apuntes y ejercicios

Repositorio de apuntes, instalaciones, diagramas y ejercicios prácticos de formación en Big Data. El contenido está organizado por sesiones y bloques de trabajo; no es una aplicación única con un comando de ejecución.

## Contenido

- **Instalaciones:** materiales de configuración del entorno y herramientas.
- **Conceptos y notas:** apuntes de clase y referencias.
- **Ejercicios por sesión:** prácticas organizadas en carpetas `Ejercicios_Clase_*`.
- **Proyectos:** prácticas de Spark y ejercicios integradores.
- **Diagramas:** archivos editables de diagrams.net, incluidos los mapas del ecosistema Big Data.
- **Pruebas de entorno:** pequeños scripts de comprobación.

## Estructura principal

```text
.
├── assets/
├── conceptos/
├── instalaciones-01/
├── instalaciones-02/
├── notes/
├── Ejercicios_Clase_*/

├── projects_morning/
├── proyec-spark-01/
├── Big_Data_Ecosystem.drawio
└── Big_Data_Ecosystem_2.drawio
```

## Cómo utilizarlo

1. Navega a la sesión o bloque que quieras consultar.
2. Lee las instrucciones incluidas en esa carpeta.
3. Abre los diagramas `.drawio` con [diagrams.net](https://app.diagrams.net/).
4. Ejecuta los ejercicios desde el entorno y con las dependencias indicadas en cada práctica.

No existe un único comando de instalación o ejecución para todo el repositorio: cada ejercicio puede tener requisitos distintos.

## Tecnologías y temas

El material cubre el ecosistema Big Data y prácticas relacionadas con Spark, Python, herramientas de datos, instalaciones y conceptos de ingeniería de datos. Consulta cada carpeta para conocer la versión concreta y los requisitos de cada ejercicio.

## Estado y contribuciones

Material de aprendizaje en evolución. Las carpetas se conservan como histórico de prácticas y sesiones. Si añades un ejercicio, incluye su objetivo, requisitos, pasos de ejecución y resultado esperado en un README dentro de la carpeta correspondiente.

---

**Nota:** este repositorio contiene apuntes y ejercicios propios. Las referencias o herramientas de terceros deben atribuirse a sus autores y conservar sus licencias.
